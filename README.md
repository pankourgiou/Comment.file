# Comment.file
το προβλημα ξεκιναει κ τελειωνει στη ιδια ιδεα...διαφορετικο ειναι να επενδυεις
κεφαλαια, να δουλευεις σε δουλεια κ να επεξεργαζεσαι πληροφοριες.
Συγκεκριμενα ο Η/Υ επεξεργαζεται δεδομενα/ πληροφοριες..αυτο ειναι επεξεργασια..σαν παιγνιο κ οχι δουλεια
η δουλεια ειναι πιο γρηγορη..ο γιατρος δουλευει..εχει το παιδι γριπη...παιρνεις αμαξι πας γιατρο ο γιατρος πρεπει να δρασει
με ταχυτητα. η επεξεργασια πληροφοριας μπορει να ειναι χαλαρη σαν παιχνιδι.
επηρρεαζει τη φυση κ το συνολο της δουλειας χωρις να την αντικαθιστα αλλα ουτε την υποκαθιστα..την αλλαζει.
Ομως η κακοτητα στη χρηση..η υπερβολικη καθυστερηση..δηλωνει οτι κατι στραβα παει...
συμπερασματικα εχεις απειρες ελευθεριες οταν εισαι φιλικος προς το χρηστη κ πρεπει να ειμαστε φιλικοι προς το χρηστη οσο και να δημιουργειται χωρος.
Η ΤΝ οπως και αλλα ανθρωπινα μεσα μπορουν
να περιοριστουν γινεται κ με αυτορρυθμιση αλλα κ με σωστη παιδεια.
στο μελλον θα υπαρχει απλα αλλα μπορει να λιγοστεψουμε..πολυ..achtung!
